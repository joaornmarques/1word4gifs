# 1 Word 4 Gifs

How well do you know the internet?

## What it is?

1 Word 4 Gifs is a web game based on Giphy API. The name is self explanatory, the challenge is to guess the word in common between series of four GIF images in 20 seconds. The more words guessed, better the score will be.

## Can I play it?

For sure! It's live at [1word4gifs.co.nf](http://1word4gifs.co.nf/)

## Word base

Words live in `js/words.js`, generated by `tools/build_words.py` (edit the lists there, then run `python3 tools/build_words.py .`).

Each word has a knowledge level (1 universal, 2 pop culture, 3 niche) and a spelling level (1 easy to 3 tricky). Together they set the word's difficulty, and the game raises the difficulty as the score grows. Portuguese translations and common misspellings are also accepted as answers. Adult words and R-rated GIFs only appear when adult mode is turned on in the intro.
